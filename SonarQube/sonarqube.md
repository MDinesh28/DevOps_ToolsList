# 🚀 SonarQube Installation on Ubuntu EC2

SonarQube is an open-source platform for continuous inspection of code quality. It detects bugs, code smells, and security vulnerabilities.

---

## ✅ Prerequisites

Before proceeding, ensure the following:

| Item           | Requirement                              |
|----------------|-------------------------------------------|
| OS             | Ubuntu 20.04+                             |
| Memory         | Minimum 2 GB RAM (4 GB recommended)       |
| Java           | OpenJDK 17 (required by SonarQube 10.x)   |
| Internet       | Required to download packages             |
| Port           | Port **9000** must be open in your EC2 Security Group |

---

## 📦 Installation Steps

### 1. Update and Install Java
### 2.Create SonarQube User
### 3. Download and Set Up SonarQube
### 4. Create a Systemd Service
### 5. Reload and Start the Service


### Access SonarQube UI
#### Open your browser:
    http://<your-ec2-public-ip>:9000


## Default credentials:

    Username: admin

    Password: admin

### You’ll be prompted to change the password on first login.
